## 📋 Course Syllabus

### Course Overview
Understand operating system concepts, process management, memory management, and file systems. Learn how OS manages hardware resources and provides services to applications.

### Topics Covered

#### 1. Introduction to Operating Systems
- OS functions and objectives
- Types of operating systems
- OS structure and components
- System calls and API

#### 2. Process Management
- Process concept and states
- Process control block (PCB)
- Process creation and termination
- Context switching
- Inter-process communication (IPC)

#### 3. CPU Scheduling
- Scheduling criteria
- FCFS, SJF, Priority scheduling
- Round Robin scheduling
- Multilevel queue scheduling
- Real-time scheduling

#### 4. Process Synchronization
- Critical section problem
- Mutex and semaphores
- Monitors
- Classic synchronization problems
- Deadlock (prevention, avoidance, detection)

#### 5. Memory Management
- Memory hierarchy
- Contiguous memory allocation
- Paging and segmentation
- Virtual memory
- Page replacement algorithms
- Thrashing

#### 6. File Systems
- File concepts and operations
- Directory structure
- File allocation methods
- Free space management
- Disk scheduling algorithms

#### 7. I/O Systems
- I/O hardware and software
- Device drivers
- Buffering and caching
- Disk management

#### 8. Security and Protection
- Authentication and authorization
- Access control
- Security threats
- Protection mechanisms

### Learning Outcomes
- Understand OS architecture
- Manage processes and threads
- Implement synchronization
- Optimize resource allocation
