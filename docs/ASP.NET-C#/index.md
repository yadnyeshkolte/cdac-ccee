## 📋 Course Syllabus

### Course Overview
Master C# programming and ASP.NET framework for building modern web applications. Learn .NET architecture, MVC pattern, Entity Framework, and develop scalable enterprise solutions.

### Topics Covered

#### 1. C# Programming Fundamentals
- C# syntax and data types
- Variables, operators, and expressions
- Control flow statements
- Methods and parameters
- Exception handling
- Collections and generics

#### 2. Object-Oriented Programming in C#
- Classes and objects
- Properties and indexers
- Inheritance and polymorphism
- Interfaces and abstract classes
- Delegates and events
- LINQ (Language Integrated Query)

#### 3. .NET Framework
- .NET architecture and CLR
- Assemblies and namespaces
- Garbage collection
- .NET class library
- File I/O and streams

#### 4. ASP.NET MVC
- MVC architecture pattern
- Controllers and actions
- Views and Razor syntax
- Models and data binding
- Routing and URL patterns
- Filters and attributes

#### 5. Entity Framework
- ORM concepts
- Code-First approach
- Database context and DbSet
- LINQ to Entities
- Migrations
- Relationships and navigation properties

#### 6. Web Development
- HTML helpers and tag helpers
- Form handling and validation
- State management (Session, ViewState)
- Authentication and authorization
- Web API development
- RESTful services

#### 7. Advanced Topics
- Dependency injection
- Unit testing
- Security best practices
- Performance optimization
- Deployment strategies

### Learning Outcomes
- Develop web applications with ASP.NET MVC
- Write efficient C# code
- Implement data access with Entity Framework
- Build secure, scalable applications
