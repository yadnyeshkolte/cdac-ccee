# Software Development Methodologies

## Module Overview

**Duration:** 48 hours (32 theory + 16 lab)  
**Evaluation:** 65 marks (CCEE: 25 + Lab: 20 + Internals: 20)

This module covers modern software development practices including version control, software engineering principles, Agile methodologies, DevOps, containerization, and testing.

---

## Module Structure

### 1. Git (4 hours)
- Version control systems
- Git fundamentals
- Branching and merging
- Collaboration workflows

### 2. Software Engineering & DevOps (28 hours)
- Software development lifecycle
- Requirements and design engineering
- Agile and Scrum
- DevOps practices
- Docker containerization
- Kubernetes orchestration

### 3. Testing & Integration (16 hours)
- Software testing fundamentals
- Test automation with Selenium
- Continuous Integration with Jenkins
- Delivery pipelines

---

## Learning Objectives

By the end of this module, you will be able to:

✓ Use Git for version control and collaboration  
✓ Understand software development methodologies  
✓ Apply Agile and Scrum practices  
✓ Implement DevOps workflows  
✓ Containerize applications with Docker  
✓ Orchestrate containers with Kubernetes  
✓ Write automated tests with Selenium  
✓ Build CI/CD pipelines with Jenkins
