## 📋 Course Syllabus

### Course Overview
Develop enterprise-level web applications using Java EE technologies. Master Servlets, JSP, Spring Framework, Hibernate ORM, and build scalable, maintainable web solutions.

### Topics Covered

#### 1. Servlets
- Servlet lifecycle and architecture
- HttpServlet and request/response handling
- Session management
- Filters and listeners

#### 2. JavaServer Pages (JSP)
- JSP syntax and directives
- Scriptlets, expressions, and declarations
- JSP implicit objects
- Custom tags and JSTL

#### 3. Spring Framework
- Spring Core (IoC and DI)
- Spring MVC architecture
- Controllers and request mapping
- Form handling and validation

#### 4. Hibernate ORM
- Object-Relational Mapping concepts
- Hibernate configuration
- Entity mapping and annotations
- HQL and Criteria API

#### 5. RESTful Web Services
- REST principles
- Creating REST APIs
- Spring REST controllers

#### 6. Spring Security & Microservices
- Authentication and authorization
- JWT authentication
- Microservices architecture
